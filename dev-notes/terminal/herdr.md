# Herdr Terminal

## Workspace

| Action | Shortcut |
|---|---|
| Navigate workspaces | `Ctrl+B → W` |
| New workspace | `Ctrl+B → Shift+N` |
| Rename workspace | `Ctrl+B → Shift+W` |
| Remove workspace | `Ctrl+B → Shift+D` |

## Tabs

| Action | Shortcut |
|---|---|
| New tab | `Ctrl+B → C` |
| Next tab | `Ctrl+B → N` |
| Previous tab | `Ctrl+B → P` |
| Rename tab | `Ctrl+B → Shift+T` |
| Remove tab | `Ctrl+B → Shift+X` |

## Panes

| Action | Shortcut |
|---|---|
| Split right | `Ctrl+B → V` |
| Split down | `Ctrl+B → -` |
| Navigate | `Ctrl+B → H/J/K/L` |
| Rename pane | `Ctrl+B → Shift+P` |
| Remove pane | `Ctrl+B → X` |
| Zoom pane | `Ctrl+B → Z` |

## Navigation

`Ctrl+B → G` — jump/search workspace, tab, pane, agent

`Ctrl+B → B` — toggle sidebar

`Ctrl+B → Q` — detach


## Save & Restore workspace [https://github.com/chandrasekharan98/herdr-workspace-save]
`prefix + Shift + S` - Save
`prefix + Alt + W` - Restore
